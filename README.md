# Generador de recibos

Editor de recibos estilo ticket que funciona en local, en un único archivo HTML, sin dependencias ni conexión a internet.

## Uso

Abre `index.html` con doble clic en cualquier navegador moderno.

- **Contenido**: añade, reordena (arrastrando o con ↑↓), duplica o elimina secciones: encabezado con logo, fecha y hora, datos, artículos, separadores, totales, texto y código de barras (Code 128).
- **Totales automáticos**: subtotal, descuento, impuesto incluido o añadido, propina, forma de pago y cambio.
- **Papel y formato**: ancho de 58, 80 o 112 mm, bordes rectos o dentados, tipografía, colores, márgenes y formato de moneda.
- **Plantillas** con datos ficticios: minimarket, restaurante, cafetería, estación de servicio, recibo de pago y en blanco.
- **Salida**: descarga en PNG de alta resolución, impresión o PDF, y guardar/abrir recibos en `.json`. El trabajo en curso se guarda en el navegador.

## Uso responsable

Pensado para emitir recibos de tu propio negocio, llevar tu contabilidad, hacer maquetas o tener datos de prueba. No lo uses para hacer pasar un recibo por el de otro comercio ni como prueba de una compra que no ocurrió.
